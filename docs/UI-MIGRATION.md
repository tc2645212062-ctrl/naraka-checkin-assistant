## 设计方案

以福利中心的每日任务册为主视觉：固定侧栏、清晰的当日状态、一张逐项任务表，而非多个重复数字卡片。首页依次回答“今天怎样、还有什么、什么时候继续”。左对齐，窗口保留 Windows 标题栏与缩放、键盘焦点、Tab、Ctrl+1…4、Ctrl+S、Esc 停止。

颜色：浅色冷白 #F5F6F8、纸面 #FFFFFF、正文石墨 #242932、次要文字 #626C7A、暗金 #856421；深色蓝灰底 #191E26、面板 #232B36、正文 #E7EAF0、暗金 #D0AE65。成功与警告均附文字，不只依赖颜色。

字体：Microsoft YaHei UI 用于正文和控件；SimSun 仅用于中文产品字标，避免模仿 macOS 标题栏。布局采用可缩放的 Qt 布局与滚动页面，主要按钮高 36 逻辑像素。

动效：页面切换短淡入、六段完成标记的短状态更新，无持续呼吸或漂浮。输入始终可用，重入会停止上一次动画。Windows 关闭客户区动画或应用选择“减少动画”时直接呈现。借鉴 apple-hig 的目的、清晰反馈与可取消动效；窗口、键盘和通知遵循 Windows 使用习惯。

审视方案后删去泛用的大数字统计卡片和渐变背景；采用带结果来源的任务行，凸显此工具最重要的“确实完成了吗”。金钥匙常驻能力说明：本项目尚无实机提交成功证据。模拟模式独立横幅、标签和临时数据库，不能伪装真实完成。
