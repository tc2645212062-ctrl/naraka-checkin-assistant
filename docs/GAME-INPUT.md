# 游戏自动操作模块

游戏本体使用管理员权限，普通助手的模拟输入未成功。为此新增独立的 `GameInputBroker.exe`，由当前用户一次性批准安装，在 Windows 计划任务的交互会话中按需运行。助手主体和微信操作继续使用普通权限。

## 本次授权的具体内容

- 安装文件：`C:\Program Files\NarakaCheckinAssistant\GameInputBroker.exe`。目录及程序仅 SYSTEM/管理员可修改，普通用户只读和执行。
- 注册任务：`NarakaCheckinAssistant-GameInput`，当前用户、最高权限、仅已登录用户可交互、没有每天/开机触发器。单次最多运行 9 分钟；客户端断开后结束。
- 只认 `E:\Naraka\tool\LootHoarder.exe` 与 `E:\Naraka\program\NarakaBladepoint.exe`，检查网易有效数字签名。
- 普通助手通过当前用户专用本机命名管道请求截图或七种固定动作：启动游戏、公告空格继续、已保存账号进入、标题页进入、Esc 关闭白泽月卡弹窗、Esc 关闭已识别活动宣传弹窗、核验大厅后正常退出。
- 每个动作在高权限模块内重新截图，并核对嵌入程序的固定按钮图像；不接受调用方提供的路径、按键或点击坐标。不选择其他账号、不输入密码、不开始对局、不领取游戏内月卡。退出动作必须同时匹配两处大厅标识才发出正常关闭请求；日常流程会在确认大厅后退出本轮启动的游戏，再回微信领取积分。
- 不操作 UAC、安全桌面或锁屏。普通助手检测到扫码、验证码、网络失败、未知页面时停止。动作后页面未变化不会反复点击。
- 不改变 Windows 的 UAC 设置，不把整个签到助手设置为管理员运行。新的模块授权与之前“只启动官方启动器”的授权分别注册、分别可撤销。

## 安装、验证、撤销

在项目目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Build-GameInput.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Install-GameInput.ps1
```

第二条命令会要求用户手动允许一次 Windows PowerShell 的 UAC。之后日常调用已注册任务不再请求这次授权。普通权限安装前计算文件 SHA256，提权后再次检查，防止安装期间文件被替换。

撤销：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Install-GameInput.ps1 -Remove
```

撤销停止并移除本模块的计划任务，保留程序文件和签到数据；不会删除此前独立的官方启动器任务。

在助手“执行计划 → 游戏登录”开启“登录积分未完成时，自动启动并登录端游”。启用后仍先检查小程序：已完成直接跳过，可领取直接领取；只有前置条件未满足才调用游戏模块。看到游戏大厅之后，还必须刷新小程序，领取并观察到“已完成”，才算积分任务成功。

此版按钮模板来自本机 2560×1600 游戏与 1538×932 启动器，已测试同比例缩放。游戏界面、宽高比或登录流程改变可能需要更新模板；模板不匹配会停止，不盲点。版本更新后如发行者签名不符同样停止。截图证据仅在本机，可能包含账号及角色信息。

模块只处理已观察过的页面，保存账号是否长期有效取决于官方登录状态。游戏已经运行时复用现有窗口，不强制退出或重启。

用户已同意重启验证时使用：

```powershell
& 'D:\NarakaCheckinAssistant\.venv\Scripts\python.exe' scripts\Verify-GameLogin.py --run --restart
```

命令会先获取自动化互斥锁、识别大厅，才发出一次正常关闭请求；没有退出时停止，不强杀游戏。之后自动走登录步骤并保存证据。默认不加参数仅观察当前游戏页面；加 `--run` 且不加 `--restart` 会复用游戏。此验证脚本不领取小程序积分，也不写入签到完成记录。
