# 图标模板来源

这些小尺寸图标从本机已观测的微信 / 永劫无间小程序界面裁切，仅用于本地识别，不包含头像、账号或聊天正文。

- `signed.png`、`unsigned.png`：2026-09-22 福利中心日历格。
- `discover.png`：2026-09-22 微信侧边发现图标。
- `chat.png`：2026-09-23 未选中的聊天图标左部（避开可变未读角标）。
- `search.png`：2026-09-23 微信顶部搜索框放大镜图标。
- `popup-close.png`：2026-09-22 首页活动弹窗关闭按钮。
- `back.png`：2026-09-22 小程序左上返回箭头。

图标匹配限制在目标窗口或相应导航区域，配置缩放范围与阈值在 `recognition.py` 和 `automation.py` 中。未达到阈值即停止，不按旧坐标猜测点击。
